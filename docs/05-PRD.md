## 1. 产品概述

### 1.1 产品定位

> 一个轻量、可运行的 Agent 运行沙箱与离线评测平台：任何 Agent 通过统一 Adapter 接入后，可在仿真环境中执行；平台负责 trace、用例管理、行为断言、越权拦截、badcase 归因与版本回归。
>
> **平台统一基础设施，用例与判定标准由业务方提供。**

### 1.2 目标用户

| 用户 | 核心任务 |
|---|---|
| Agent 开发者 / 业务团队 | 注册自己的 Agent，跑通用例，定位问题 |
| 评测 / 效能 / AI 平台团队 | 维护用例与 Rubric，批量回归，看报告 |
| 管理层 / 合规 | 查看风险拦截与验收报告 |

### 1.3 核心价值

| 价值 | 对应缺口 |
|---|---|
| 管控可编程 | P1 |
| 过程可观测 | P2 |
| 结果可回归 | P3 |
| 评测基础设施可复用 | P4 |

### 1.4 产品边界

- 做：离线仿真、Mock 工具、批量运行、trace、回归、双范式；
- 不做：多租户、真实系统集成、在线流量、容器隔离、Skill 市场。

## 3. 功能规格

### FR-01 · Agent 注册与元数据

**描述**：业务方实现 `AgentAdapter`，提供 metadata（含业务意图声明），注册到平台。

**输入**：`agent_id`、`name`、`paradigm`、`adapter_type`、`adapter_ref`、`capabilities`、`intents`（业务意图 → B1–B6 行为类别）。

**行为**：
1. 加载 Adapter；
2. 调用 `metadata()`；
3. 校验必填字段与 paradigm；
4. 写入 Agent 表。

**验收标准**：
- 注册成功后有唯一 `agent_id`；
- metadata 缺字段时给出结构化错误；
- `intents` 必须映射到 B1–B6；未声明的意图走 B6/B5 兜底；
- Adapter 加载失败不写入脏数据。

**缺口**：P4（可复用接入）。

### FR-02 · Agent 版本管理

**描述**：每次注册或更新记录版本与配置指纹。

**验收标准**：
- 同一 Agent 可保留多个版本；
- Run 绑定具体版本；
- 回归对比可指定版本。

**缺口**：P3（可回归）。

### FR-03 · 用例导入与校验

**描述**：从 JSON/YAML 导入用例，按 Case Schema 校验。

**校验项**：
- 必填字段；
- `expected_route` 合法；
- `forbidden_behavior` 非空；
- `relevant_message_ids` 指向存在的消息；
- `source` 含来源与许可；
- `label` 合法。

**验收标准**：
- 非法用例被拒绝并给出字段级错误；
- 导入成功的用例可按 label/agent 筛选；
- 不修改业务方原始文件。

**缺口**：P3。

### FR-04 · 用例集管理

**描述**：把用例组织为 CaseSet，支持版本、标签、启停。

**验收标准**：
- 一个 CaseSet 可包含多个 Case；
- 支持按 label 过滤；
- 运行时可指定 CaseSet；
- 用例内容由业务方维护，平台不生成通用用例。

**缺口**：P3。

### FR-05 · Rubric 配置

**描述**：业务方按平台格式配置评测维度、权重、判定方式、通过阈值。

**校验**：
- 权重和为 1；
- 每个维度有 `judge_type`；
- 至少一个 `hard_rule`；
- `pass_threshold` 在 0–1。

**验收标准**：
- 同一平台可加载至少两套 Rubric（collab / restricted）；
- Rubric 可被 Run 引用；
- 平台不硬编码业务权重。

**缺口**：P3 / P4。

### FR-06 · 单 case 运行

**描述**：指定 Agent、Case、Rubric、模式，执行一次。

**行为**：
1. 创建 `run_id`；
2. Harness 加载 case；
3. 构造 `TaskInput`；
4. 注入 ToolRegistry 与 TraceRecorder；
5. 调用 Adapter；
6. 落盘 trace 与结果。

**验收标准**：
- 单 case 可端到端跑通；
- 失败时 trace 保留；
- 同一 case 重复运行结果可复现（Mock）。

**缺口**：P2。

### FR-07 · 批量运行

**描述**：按 CaseSet 批量执行，串行为主。

**验收标准**：
- 支持进度显示；
- 单 case 失败不中断整批；
- 输出汇总结果；
- 运行配置可保存/复用。

**缺口**：P3。

### FR-08 · Trace 记录

**描述**：每个节点、工具调用、围栏结果写入结构化 trace。

**必填字段**：`seq`、`node`、`ts`、`decision`、`tool`、`params`、`fence_checks`、`executed`、`output_summary`。

**验收标准**：
- 每个 case 有完整 trace；
- trace 可导出 JSON；
- trace 不含密钥/敏感信息；
- 评测脚本可只依赖 trace 计算硬规则指标。

**缺口**：P2。

### FR-09 · Trace 查看

**描述**：CLI 与 Streamlit 查看 trace。

**验收标准**：
- 可按 run/case 查询；
- 可看到节点顺序、工具调用、围栏结果；
- 可定位失败步骤。

**缺口**：P2。

### FR-10 · 回归对比

**描述**：对比两次 Run 的指标与 case 级变化。

**输出**：
- 指标 diff；
- 通过→失败 / 失败→通过；
- 新增失败；
- 成本变化。

**验收标准**：
- 可指定 base/target；
- diff 结果可导出；
- 能识别"修 A 坏 B"。

**缺口**：P3。

### FR-11 · 报告导出

**描述**：生成 JSON/Markdown 报告。

**结构**：Run Spec / Evidence / Acceptance（借鉴 PYRA）。

**验收标准**：
- 报告含指标、失败 case、风险项；
- 可被面试演示；
- 不含敏感数据。

**缺口**：P3。

### FR-12 · Mock 工具注册与执行

**描述**：工具实现 `ToolAdapter`，注册到 ToolRegistry。

**验收标准**：
- 读工具自动执行；
- 变更工具默认 Mock；
- 支持正常/业务错误/系统故障三类响应；
- 同输入同输出。

**缺口**：P1。

### FR-13 · 权限围栏

**描述**：工具执行前做 Schema、权限、前置条件校验。

**顺序**：Schema → 权限 → 前置条件 → 确认 → 执行 → 审计。

**验收标准**：
- 5 条围栏可配置；
- 越权 case 被拦截；
- 合法 case 不被误拦；
- 围栏结果写入 trace。

**缺口**：P1。

### FR-14 · 人工确认

**描述**：高风险任务触发确认；飞书卡片或 Streamlit 按钮。

**验收标准**：
- 确认/驳回可闭环；
- 驳回后任务终止；
- 超时 30min 标记过期；
- 确认结果写入 trace。

**缺口**：P1。

### FR-15 · Sample A 飞书入口

**描述**：Sample A 通过飞书长连接接收 @，执行后回写。

**验收标准**：
- 群里 @ 可触发；
- 回复消息成功；
- 卡片确认可闭环；
- 事件幂等。

**缺口**：P4（示例接入）。

### FR-16 · Sample B 接入（P2）

**描述**：最小售后工单 Agent 接入平台，使用 restricted Rubric。

**验收标准**：
- 实现 Adapter；
- 20–30 条用例可跑；
- 静态红线可验证；
- 接入耗时 ≤ 30min。

**缺口**：P4（跨范式）。

### FR-17 · 成本统计

**描述**：记录每次 LLM 调用的 token 与耗时。

**验收标准**：
- 按 run/case 汇总；
- 报告展示；
- 可设置预算告警。

**缺口**：P2（可观测）。

### FR-18 · 异常与重试

**描述**：Harness 处理超时、Adapter 异常、工具失败、trace 不完整。

**验收标准**：
- 单 case 失败不中断批量；
- 超时/失败有明确状态；
- 重试次数可配置；
- 失败原因写入 trace。

**缺口**：P2。

## 5. 交互流程

### 5.1 CLI 流程

```
agent register → case import → case validate → run →
trace show → report compare → report export
```

### 5.2 Streamlit 流程

```
Agents → Cases → Runs → Trace → Compare → Report
```

### 5.3 失败路径

| 场景 | 行为 |
|---|---|
| Adapter 加载失败 | 注册失败，提示模块路径 |
| Case 校验失败 | 拒绝导入，字段级错误 |
| 单 case 超时 | 标记 TIMEOUT，继续批量 |
| 工具失败 | 记录，重试 1 次，仍失败则降级 |
| 围栏拒绝 | 不执行工具，写入 trace，走 verify |
| 人工驳回 | 任务终止，状态 REJECTED |

## 6. 数据与状态

| 对象 | 存储 | 说明 |
|---|---|---|
| Agent / Version | SQLite | 注册信息 |
| Case / CaseSet | JSON + SQLite 索引 | 内容归业务方 |
| Rubric | YAML/JSON | 业务方配置 |
| Run / RunResult | SQLite | 运行记录 |
| Trace | JSON 文件 + SQLite 索引 | 评测输入 |
| Report | JSON/Markdown | 输出 |

**状态机**：

```
CREATED → RUNNING → WAITING_CONFIRM → RUNNING → DONE
                  ↘ FAILED
                  ↘ TIMEOUT
                  ↘ REJECTED
```

## 7. 权限与安全（POC 边界）

| 项 | 做 | 不做 |
|---|---|---|
| 工具权限 | 应用层围栏（Schema/权限/前置条件） | 企业级 RBAC、IAM |

| 审计 | trace + 围栏记录 | 合规审计系统 |
| 密钥 | 环境变量 | 密钥管理服务 |
| 真实系统 | Mock | Jira/GitLab/CI |

## 8. 验收标准

### 8.1 平台级

- 可注册 Sample A；
- 可导入 ≥1 个 CaseSet；
- 可批量运行并产出 trace；
- 可对比两次运行；
- 可导出报告；
- 新增 Simple Agent 接入 ≤ 30min。

### 8.2 Sample A

- 飞书 @ 可触发；
- 越权 case 100% 拦截；
- 交接类 case 有确认/驳回；
- trace 完整。

### 8.3 文档级

- 每个 FR 有验收标准；
- 每个 FR 可追溯到 G1 缺口；
- MVP 范围冻结。
