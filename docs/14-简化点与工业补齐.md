## 0. 文档导读

### 0.1 这份文档的目的

给每个模块一套统一表述：**原型实现了什么 → 主动简化了什么 → 工业落地还要补什么**。

### 0.2 读者与使用方式

| 读者 | 怎么用 |
|---|---|
| 候选人 | 被问"你这个是不是玩具"时，按模块回答 |
| 面试官 | 判断候选人是否清楚 POC 与生产的 gap |

### 0.3 本文包含什么

```
§1 统一表述模板
§2 12 个模块的对照
§3 哪三件事不能砍
§4 生产化路线
§5 一页速记
```

### 0.4 核心结论（30 秒版）

> 这个项目不是"缩小版工业平台"，而是**只保留能证明产品逻辑的最小闭环**：
> 围栏、trace、回归不能砍；多租户、容器沙箱、真实系统、成本治理是生产化增量。

### 0.5 本文不解决什么

- 不提供生产排期；
- 不假装已经实现工业能力；
- 不覆盖所有厂商能力。

## 1. 统一表述模板

每个模块按三段说：

> **当前原型**：我做了什么，支撑哪条评测。
> **✂️ 本次简化**：为了 POC，我主动砍了什么。
> **📌 工业补齐**：真实业务落地还要补什么，为什么。

> 原则：不藏简化点，不吹工业级；主动说 gap，比被问出来更加分。

## 2. 12 个模块对照

### 2.1 IM 接入

| 项 | 内容 |
|---|---|
| 当前原型 | 飞书自建应用 + 长连接 + @ 解析 + 回复 + 交互卡片 + 待确认任务 |
| ✂️ 简化 | 单私有组织；无多租户；无频控、敏感词、审批流对接 |
| 📌 工业补齐 | 租户隔离、限流、审计、组织架构/身份、卡片权限、消息安全 |
| 一句话 | "我验证的是 Agent 侧交互闭环，IM 只是载体。" |

### 2.2 上下文筛选

| 项 | 内容 |
|---|---|
| 当前原型 | 话题/关键词规则 + BGE 语义召回 + 失败回退；drift 23.3% → 17.2% |
| ✂️ 简化 | 每 case 全量 embed；无增量消息库；无权限过滤；无会话切分；无缓存 |
| 📌 工业补齐 | 增量消费、权限感知召回、话题分割、reranker、embedding 缓存、token 预算 |
| 一句话 | "语义筛选降噪有效，但召回损失 4.4pp，工业上要混合召回。" |

### 2.3 Agent 内核

| 项 | 内容 |
|---|---|
| 当前原型 | 路由、过滤、规划、工具、自检、终止；LangGraph 编排 |
| ✂️ 简化 | 单 Agent；无多 Agent 协作；无动态工具发现；无长期记忆 |
| 📌 工业补齐 | 多 Agent/Skill/MCP、记忆、规划器、失败恢复、能力路由 |
| 一句话 | "内核是 L2：多步 + 工具 + 自检，不做多 Agent 协作。" |

### 2.4 行为分类与规则

| 项 | 内容 |
|---|---|
| 当前原型 | B1–B6 行为类别 + R1–R6 规则 + LLM 主分类 + 三类护栏 |
| ✂️ 简化 | 规则写死在代码/YAML；无规则平台、版本、灰度、生效范围 |
| 📌 工业补齐 | 规则平台、版本管理、灰度、冲突检测、审批、规则效果回归 |
| 一句话 | "规则优先、LLM 辅助；但规则治理本身还是 POC。" |

### 2.5 工具与权限围栏

| 项 | 内容 |
|---|---|
| 当前原型 | Mock 工具 + F1–F5 / T1/T2/T5；执行前拦截并写 trace |
| ✂️ 简化 | 围栏硬编码；应用层策略；无 IAM/零信任/容器隔离；不接真实系统 |
| 📌 工业补齐 | 工具网关、身份、最小权限、密钥、审计、沙箱、配额 |
| 一句话 | "围栏逻辑是真的，隔离是应用的，不是内核的。" |

### 2.6 Harness

| 项 | 内容 |
|---|---|
| 当前原型 | run_id、状态机、超时、重试、异常隔离、trace 落盘 |
| ✂️ 简化 | 单机；无集群调度；无资源配额；无多任务并发 |
| 📌 工业补齐 | 容器沙箱、配额、调度、可观测大盘、影子回放、告警 |
| 一句话 | "我做的是任务级管控，不是容器级 Harness。" |

### 2.7 评测体系

| 项 | 内容 |
|---|---|
| 当前原型 | 86 dev + 20 held-out + 24 Sample B；硬规则 + 人工 + judge；回归门禁 |
| ✂️ 简化 | 合成数据；小样本；restricted Rubric 的 answer_correctness 未定义；无线上回流；无 A/B |
| 📌 工业补齐 | 真实流量回流、分层评测集、标注平台、A/B、业务指标打通 |
| 一句话 | "闭环是真的，统计显著性和线上效度还不够。" |

### 2.8 数据

| 项 | 内容 |
|---|---|
| 当前原型 | synthetic template + 2 条手写；公开语料未接入（`source.url` 为空）；每个 case 记录来源/许可 |
| ✂️ 简化 | 无真实业务分布；无大规模标注一致性校验 |
| 📌 工业补齐 | 脱敏管道、标注平台、数据卡、许可管理、版本化数据集 |
| 一句话 | "数据合规是底线，但代表性和规模不足。" |

### 2.9 安全与合规

| 项 | 内容 |
|---|---|
| 当前原型 | 不接真实系统；日志脱敏；高风险动作 Mock + 确认 |
| ✂️ 简化 | 无等保/审计/内容安全网关/DLP/留存策略 |
| 📌 工业补齐 | 合规审计、敏感词、DLP、权限、留存、红队 |
| 一句话 | "POC 不做合规认证，只做行为围栏。" |

### 2.10 成本与性能

| 项 | 内容 |
|---|---|
| 当前原型 | token/时延统计；最大步数 8；本地模型 |
| ✂️ 简化 | 无预算告警、无缓存、无并发压测、无模型路由 |
| 📌 工业补齐 | 配额、缓存、模型路由、成本看板、压测、SLA |
| 一句话 | "本地 7B 够 POC，生产要模型路由和成本治理。" |

### 2.11 部署与多租户

| 项 | 内容 |
|---|---|
| 当前原型 | 单机 CLI + SQLite + JSON |
| ✂️ 简化 | 无多租户、无权限体系、无高可用、无备份 |
| 📌 工业补齐 | SaaS/私有化、租户隔离、HA、备份、监控 |
| 一句话 | "单机是成本边界，不是能力边界。" |

### 2.12 UI / 工作台

| 项 | 内容 |
|---|---|
| 当前原型 | CLI + JSON 报告；Streamlit 未做 |
| ✂️ 简化 | 无可视化工作台 |
| 📌 工业补齐 | 工作台、看板、权限、导出、任务中心 |
| 一句话 | "CLI 能跑通全链路，UI 是演示加分项。" |

## 3. 哪三件事不能砍

| 不能砍 | 原因 |
|---|---|
| **围栏** | 没有它，越权不可控，评测失去意义 |
| **trace** | 没有它，行为评测和 badcase 归因不成立 |
| **回归** | 没有它，迭代就是碰运气 |

> 其他都可以按 POC 成本裁剪；这三件是平台的最小闭环。

## 4. 生产化路线

### 0–3 个月（可信度）

1. held-out2：完全独立，验证 LLM + 护栏；
2. Rubric 加权引擎：按 `collab_v1` / `restricted_v1` 算综合分；
3. 摘要 prompt：引用所有使用的 `message_id`；
4. Streamlit 工作台：演示与排查；
5. 混合上下文筛选：BGE + 关键词兜底。

### 3–6 个月（治理）

1. 真实脱敏数据接入；
2. 规则平台：版本、灰度、生效范围；
3. 工具网关 + 身份 + 最小权限；
4. 多租户与审计；
5. 成本看板与配额。

### 6–12 个月（规模化）

1. 容器沙箱与集群调度；
2. 线上流量影子回放；
3. A/B 实验与业务指标打通；
4. 标注平台与数据回流；
5. 内容安全、合规、红队。

---

## 5. 一页速记

> **POC 证明的是产品逻辑：接入、沙箱、trace、评测、回归、双范式。**
> **生产要补的是治理与规模：多租户、权限、真实系统、成本、线上数据。**
> **主动说 gap，比假装工业级更可信。**
